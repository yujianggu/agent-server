# Codex UI replica

独立的界面交互原型，浏览器打开 index.html 即可使用，无需安装依赖。

页面分为四部分：顶部横跨全宽的独立头部，下方依次为左侧固定图标菜单、中间可折叠的二级菜单、右侧独立内容区。头部高度为 48px，三个下方区域占据剩余高度。桌面默认宽度为 64px / 268px / 剩余空间；窄屏二级菜单采用覆盖抽屉。底部输入区保留项目上下文。头部采用线性图标：左侧前进/后退与侧栏开关，中部文件夹与当前标题，右侧更多操作、会话搜索及项目信息面板。
也可在本目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`。

已实现：创建会话、消息和历史持久化、打开历史会话、搜索、项目名称修改、侧栏折叠、浅深色主题、设置/技能/自动化占位页、模型与强度选择、附件文件名、Enter 发送及 Shift+Enter 换行。
