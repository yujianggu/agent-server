# ChatGPT 网页工作区原型

本地 Web 原型保留已确认的 Codex 头部，头部以下参考 [ChatGPT 网页版](https://chatgpt.com/)。默认打开工作模式的新聊天首页。项目、历史会话、建议卡片和插件示例均使用本地原型数据。

## 页面框架

- **头部**位于页面顶部，横跨整个页面，显示当前会话和窗口工具。
- **一级图标菜单**位于头部下方的页面最左侧，提供首页、资料空间、定时任务、插件和探索等入口。
- **内容区**位于一级图标菜单右侧。聊天页面通常包含两个部分。
  - **二级菜单**位于内容区左侧，显示置顶、项目和最近聊天等列表。
  - **聊天区**位于二级菜单右侧。新聊天首页可以切换聊天／工作模式。工作模式下可选择项目、添加文件或通过建议卡片填入草稿。打开历史会话后，消息和输入框回到会话布局。

资料空间、定时任务和插件使用各自的二级菜单和内容页。头部的返回与前进可以在这些页面和聊天会话之间切换。

### 头部控件

| 位置 | 控件 | 操作 |
| --- | --- | --- |
| 1 | 显示／隐藏侧边栏 | 从头部最左侧切换二级菜单的可见状态 |
| 2 | 返回 | 位于二级菜单上方靠右，回到上一个浏览过的会话 |
| 3 | 前进 | 位于返回右侧，与二级菜单右边缘对齐 |
| 4 | 会话名称 | 显示当前会话的名称 |
| 6 | 更多 | 打开当前会话的操作菜单 |
| 7 | 摘要 | 查看会话名称、消息数、最近提问和回复 |
| 8 | 标签页 | 打开或关闭右侧面板 |

鼠标悬停在图标上时显示中文提示。侧边栏图标根据当前状态显示「显示侧边栏」或「隐藏侧边栏」。第 5 项尚未指定。

二级菜单隐藏时，前进按钮右侧显示编辑图标，悬浮提示为「新聊天」。点击后开始新聊天并聚焦输入框。二级菜单展开时，头部隐藏该图标。

### 一级和二级菜单

| 入口 | 已对照的菜单 |
| --- | --- |
| 首页 | 项目和最近两组支持折叠、分组选项与单行操作。最近聊天可按聊天模式和项目归属筛选。 |
| 资料空间 | 全部、你的条目、与你共享、最近和回收站。侧栏与页内「创建」提供相同选项。 |
| 定时任务 | 新建任务、搜索定时任务、已暂停和状态筛选。筛选项为已开启、已暂停、已完成。 |
| 插件 | 插件、技能、已安装；侧栏搜索仅查已安装项。添加菜单含创建插件、上传插件压缩包、添加自定义 MCP 服务器。 |
| 探索 | 依次为项目、图像、健康、站点、地图、GPT、Codex。站点默认固定，点击进入资料空间的站点分类。 |
| 底部入口 | 用量和个人资料分别通过独立菜单打开。 |

菜单的固定、筛选、排序和项目操作均在本地执行。探索中的图像、健康、地图、GPT 和 Codex 使用占位入口。

## 本地运行与验证

在仓库根目录启动预览：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory workspace-prototype
```

打开 [本地预览](http://127.0.0.1:8765/)。点击左侧首页图标可从会话返回新聊天。

普通消息和选项保存在当前浏览器，临时聊天退出后清除。附件只记录文件名。资料空间支持本地分类、搜索和创建条目。定时任务支持新建、编辑、暂停和恢复示例任务，插件支持搜索、添加和移除示例。三个页面的临时状态保留到页面刷新为止。助手回复和各页面操作均为原型演示。

已有 Python Playwright 和 Chromium 时，运行浏览器测试：

```bash
python3 -B -m unittest discover -s workspace-prototype/tests -v
```

可用 Shotproof 渲染当前首页：

```bash
python3 <shotproof 技能目录>/scripts/s2c.py render http://127.0.0.1:8765/ --width 1470 --height 923 --dpr 2 --out <首页.png>
```
